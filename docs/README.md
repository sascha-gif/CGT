## Themen, die erfahrungsgemäß gebraucht werden

Als Startpunkt gedacht, nicht als Pflichtprogramm. Anlegen, wenn es dazu wirklich
etwas zu schreiben gibt:

- **Firma** — Rechtsform, Beteiligte, Zuständigkeiten, wer darf was unterschreiben
- **Lieferanten** — je Lieferant eine Datei: Konditionen, Mindestmengen, Lieferzeiten,
  Ansprechpartner, Zahlungsziel
- **Kunden / Abnehmer** — dasselbe aus der anderen Richtung
- **Produkte / Warengruppen** — was gehandelt wird, Einkaufs- und Verkaufspreise,
  Marge, HS-Codes
- **Zoll und Einfuhr** — Zolltarifnummern, Einfuhrumsatzsteuer, benötigte Papiere
- **Logistik** — Spediteure, Incoterms, Lager, Versandwege
- **Zahlungen und Banken** — Konten, Zahlungsziele, Absicherung
- **Verträge** — was wurde wann mit wem vereinbart, wo liegt das Original
- **Steuern und Buchhaltung** — Steuerberater, Fristen, USt-Themen (z. B. innergemein-
  schaftlicher Erwerb, Reverse Charge)
