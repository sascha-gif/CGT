# CGT — Coldewey Goetz Trade

Wissens-Repo für **Coldewey Goetz Trade**. Hier wird gesammelt, was sonst in
Mails, Chats und Köpfen verstreut liegt: Prozesse, Partner, Konditionen,
Entscheidungen und ihre Begründung.

Noch kein Code — das hier ist eine Ablage zum Nachschlagen.

## Ablage

| Ordner / Datei | Inhalt |
|---|---|
| [`docs/`](docs/) | Das eigentliche Wissen — ein Thema pro Datei |
| [`docs/offene-punkte.md`](docs/offene-punkte.md) | Was noch geklärt werden muss |
| `CLAUDE.md` | Arbeitsanweisung für Claude-Sessions |

## Wie schreiben

- **Eine Datei pro Thema**, Dateiname klein und mit Bindestrichen (`lieferant-xy.md`).
- **Immer dazuschreiben, warum** etwas so ist — die Entscheidung ist in einem halben
  Jahr wichtiger als das Ergebnis.
- **Datum an alles**, was sich ändern kann (Preise, Konditionen, Ansprechpartner).
  Ein Stand ohne Datum ist wertlos.
- **Keine Zugangsdaten, keine Passwörter, keine API-Schlüssel** im Repo. Auch nicht
  „nur kurz". Stattdessen notieren, *wo* sie liegen.

## Stand

Frisch angelegt, noch leer. Neue Themen einfach unter `docs/` als Markdown-Datei
anlegen und in [`docs/README.md`](docs/README.md) verlinken.
